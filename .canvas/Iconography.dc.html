Sort is three shortening rules, not a pair of arrows. Direction is carried by the chevron beside the column name, so the icon only has to say "this column is sorted". Chevron-up is the same drawing rotated and is not counted as a separate member of the family.

Hue is only ever the record's origin, and only on the icon that names the record. An icon inside a button, a row action or a field takes the text colour it sits in.

One geometry, four boxes. The stroke is compensated per size — 1.85 at 12, 1.6 at 14, 1.4 at 16, 1.12 at 20 — so every icon lands on the page at the same 1.4px weight and a 12px icon never turns into a smudge.

Construction

A 16 grid with one unit clear on every side. Terminals land on whole units; curves are drawn from the same three radii.

A 16px icon beside 13px text sits on the cap height, not the baseline — the row uses align-items:center and a 6px gap. Inside a pill the icon drops to 12 and the gap to 5, or the pill grows taller than 20px and stops matching the row.

The chevron sits at the far right of a row that opens something, and only there. It darkens from subtle to ink on hover — the second row shows the hovered state — so the affordance is quiet until the pointer is on it.
