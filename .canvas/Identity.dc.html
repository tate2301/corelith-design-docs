Twenty-four components, one slot. Each of these was drawing its own name cell before v1 — a bare string in a table, initials in a menu, nothing at all on a kanban card. They now take the same component and inherit the fallback chain, the presence dot and the truncation rule without asking.

Rules

A name never renders without its mark. If the mark cannot be resolved in time, the row shows the loading bars — it does not render the name alone and then pop the mark in.

The sub-line is optional and disappears first. At 20 and 16 there is no sub-line at all; the disambiguator moves to a trailing mono column instead.

Presence is live state, not a stored field. It renders only where a person could be reached now — never on a printed document, a reprint or an export.
