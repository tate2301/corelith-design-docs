How to customize

The kit's vocabulary.

Every page loads the same four stylesheets in the same order. marketing.css defines the rhythm — bigger type, more whitespace, wider container. Everything else stays in design-system tokens.

1. Stylesheet order

<link rel="stylesheet" href="../../tokens.css">
<link rel="stylesheet" href="../../components.css">
<link rel="stylesheet" href="../../shared.css">
<link rel="stylesheet" href="marketing.css">

2. Page skeleton

<header class="mk-nav"> ... </header>
<section class="mk-hero">
  <div class="mk-container">
    <h1 class="mk-h1">...</h1>
    <p class="mk-lede">...</p>
  </div>
</section>
<section class="mk-section"> ... </section>
<section class="mk-full-bleed mk-cta-band"> ... </section>
<footer class="mk-footer"> ... </footer>

3. The class vocabulary

Layout      .mk-container  .mk-section  .mk-full-bleed
Type        .mk-h1  .mk-h2  .mk-h3  .mk-eyebrow  .mk-lede  .mk-p
Nav         .mk-nav  .mk-nav-inner  .mk-nav-links
Hero        .mk-hero  .mk-hero-grid  .mk-mock
Features    .mk-feature-row  .mk-feature  .mk-alt[.flip]  .mk-checks
Pricing     .mk-tiers  .mk-tier[.featured]  .mk-compare
FAQ         .mk-faq  (uses native <details> / <summary>)
CTA         .mk-cta-band  (pair with .mk-full-bleed)
Footer      .mk-footer  .mk-footer-grid
About       .mk-principles  .mk-principle  .mk-team  .mk-person
Contact     .mk-contact-grid  .mk-contact-form  .mk-contact-info
