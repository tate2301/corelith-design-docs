Dashboard kit

Ten ready-to-copy screens for back-office operations — overview tiles, dense tables, posting and import flows, detail records, plus the chrome around them (settings, notifications, sign-in). The same primitives, blocks, and patterns from the design system, composed at full screen.

10 screens · Dashboard kit Desktop-first (1440) Composes: App shell + Data table + Detail view
When to reach for it

Operator-facing back office

Use the dashboard kit when you're building the staff side of a multi-tenant ERP — anyone who logs in to post, approve, reconcile, or watch the day go by. Each screen is a full composition: real navigation, real data density, real empty/loading/error states. Copy the screen that matches your shape, then strip what you don't need.

Composed from

What every screen reuses

Each screen is built from the same primitives, blocks, and patterns documented in the design system. Use these as the spec when porting a screen into your product.

Shell

App shell

Sidebar + topbar + content frame. Used by every screen in the kit. See x-app-shell.

Pattern

Data table

Filters, sticky header, bulk select, inline edit. Powers Data tables & Lists. See x-data-table.

Pattern

Detail view

Hero, summary, tabbed body, audit. Powers Journal, Batch, Employee. See x-detail-view.

Pattern

Import wizard

5-step ETL flow with per-row validation. Powers Import. See x-import-wizard.

Pattern

Settings

Section nav + save bar + permission gating. Powers Settings. See x-settings.

Pattern

Notifications

Toast stack, popover inbox, channel preferences. Powers Notifications. See x-notifications.

Pattern

Auth flow

Sign-in, OTP, workspace picker. Powers Sign-in. See x-auth.

Block

Page header + stat hero + data toolbar

Every screen uses the same chrome blocks. See page header, stat hero, data toolbar.

Desktop-first. These screens are designed at 1440 width — they're catalogue renderings, not responsive demos. For phone-grade compositions see the page templates or the cookbook recipes, which are responsive and shippable.
