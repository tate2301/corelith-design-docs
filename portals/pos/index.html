POS terminal

Touch point-of-sale for cashiers and field buyers. Built mobile-first, scaled up to tablet and counter desktop. Ships as a packaged Android/iOS app and a web PWA.

Interactive demo

Drive the POS yourself

A clickable, end-to-end POS in one page. Add items, attach a customer, charge across cash / card / EcoCash / OneMoney / split, run a refund with a supervisor PIN (use 4321), reconcile a cash-up, and read the day's Z-report. State is local — refresh resets.
