Shells

Device shells

Stash is mobile-first. A bottom-tab shell drives the phone; a left-sidebar shell takes over at desktop.

Mobile
360–414 px
Primary

Bottom-tab shell — Home · Money · Insights · More. Detail views open as bottom sheets. Safe-area aware. Pull to refresh.

Desktop
1024 px+

Left-sidebar shell. Same screens; better for managing categories, browsing long lists, and reviewing insights.

Stash is dark by default

The whole portal uses body.is-dark so the standard token cascade flips. Every block reuses the design-system primitives — Stash adds only a portal-local palette inside portals/stash/demo.html.
