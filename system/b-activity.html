Do & don't

Do

Always include "who" and "when". Without those two, it isn’t an audit trail.

Don't

Bury the most recent event below the fold. Newest first, always.

Do

Use relative time ("14 min ago") for the last 24 h, then switch to absolute ("28 May 14:38").

Don't

Append an exclamation point to system messages. Audit records read better in plain prose.

React API · CSS-only

No ActivityFeed export ships in @corelithzw/react@0.3.0. Author markup with .activity and .activity-item classes, or use a project-local component.

Composition

Activity feed composes avatar + text + (optionally) tag chips. It is the canonical what happened log on detail surfaces and ops dashboards.

Don't use this for: discussion threads — use comments thread for the why. For point-in-time audit views with diff payloads, see audit view.
