Do & don't

Do

Match tone to severity. Danger is for things that block work; info is for nice-to-knows.

Don't

Use a callout when a plain paragraph would do. Callouts cost attention.

Do

Keep callouts to two sentences. The body, then what the user can do about it.

Don't

Stack three callouts on one page. The reader stops parsing them.

React API · Deprecated

No Callout export ships. Use Alert from @corelithzw/react@0.3.0 instead — props: tone · title · description · action · icon.

Composition

Callout composes an icon + heading + body + optional action — the canonical inline notice block. Use it for soft warnings, info notes, and success banners inside a page.

Don't use this for: dismissible toast notifications — use notifications. For irrecoverable errors with a primary CTA use status state.

Responsive behaviour

ViewportBehaviour
Phone (≤ 720 px)Icon scales to 16 px; action stacks below body.
Tablet (720 – 1023 px)Icon 18 px; action inline at the end.
Desktop (≥ 1024 px)Icon 18 px; action right-aligned in the strip; max-width 60 ch on description.
