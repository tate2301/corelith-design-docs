Do & don't

Do

Use comments for the why. The activity feed is for what; comments are for context.

Don't

Reply with emoji or "+1". Use a reaction count if the platform supports it.

Do

Pin the most relevant comment to the top of the thread when investigating an exception.

Don't

Allow editing comments after 5 minutes. Edits break the audit trail.

Composition

Comments thread composes from avatar + text + button + textarea. The pattern handles threading, mentions, reactions, and resolve in one component.

Don't use this for: public-facing comment threads — this is built for an in-product collaboration model with a known mention set. For pure activity logs use activity feed.

  • Each comment is a <article> with an aria-label composed of author + relative time.
