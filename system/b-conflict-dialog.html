Do & don't

Do

Show both versions side by side. The operator decides; don’t auto-merge.

Don't

Show fields that didn’t change. Only the differences need attention.

Do

Time-stamp both versions so the operator can judge recency.

Don't

Allow "Skip for now". A conflict held in limbo will be worse later.

React API · compose with Modal

No dedicated ConflictDialog export — compose a Modal with the two-column diff body shown above. Props: open · onClose · title · footer · size="lg".

Composition

Conflict dialog composes a modal + a two-column diff body + three actions: keep mine, take theirs, merge.

Don't use this for: ordinary save errors — use an inline alert. Reserve conflict dialogs for the case where two writers genuinely raced.

Responsive behaviour

ViewportBehaviour
Phone (≤ 720 px)Defers to bottom sheet; diff columns stack vertically (yours above theirs).
Tablet (720 – 1023 px)Modal at 640 px; diff side-by-side.
Desktop (≥ 1024 px)Modal at 720 px; diff side-by-side with row-level highlight.
