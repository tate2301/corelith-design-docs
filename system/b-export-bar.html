Do & don't

Do

Keep the file ready for at least 24 hours. Operators may revisit.

Don't

Auto-download. Always offer a button so the operator chooses where the file goes.

Do

Show file name, row count, size.

Don't

Hide the bar after dismissal. Send it to the export history page instead.

React API · CSS-only

No React export — author markup with .b-export-bar. Compose ExportMenu for the format picker.

Composition

Export bar composes a row of format buttons (CSV · XLSX · PDF) + count + scope. It sits above or beneath a list / table when the operator wants to bulk-export the visible rows.

Don't use this for: single-record exports — those go in the page header action cluster. For scheduled exports use settings.

Responsive behaviour

Tablet (720 – 1023 px)Inline button cluster; count below.
Desktop (≥ 1024 px)Inline buttons + count + scope label.
