Highlights

A list of things worth knowing this shift — wins, anomalies, milestones. Designed to be scannable in 10 seconds.

Stable .highlights GlanceablePer-shift

Default

Three or four highlights. Each one sentence. Tone indicates kind.

Do & don't

Do

One sentence per item. Past tense for wins, future tense for warnings.

Don't

Pad the list. Three highlights is honest; six is noise.

Do

Use the canonical status dots — ok for good news, attention for warnings.

Don't

Show generic system messages here. Highlights are about the operator’s business.

React API · CSS-only

No React export — author markup with .b-highlights + .b-hl-item classes.

Composition

Highlights composes 3 – 4 inline bullets of single-line context — used at the top of an overview to call out the day's most-relevant facts.

Don't use this for: primary KPIs — use stat hero. For longer narrative text use page intro.

Responsive behaviour
