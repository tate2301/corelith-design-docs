Do & don't

Do

Use this when the operator edits dozens of records in a session.

Don't

Use it for one-off setups. A simple form page beats it.

Do

Pin the search input at the top of the left panel. Always one keystroke away.

Don't

Auto-select the first record on load. Show an empty-state until the operator picks.

React API · CSS layout

CSS layout block — author with the .b-master-shell container; compose data table + inline edit + drag-reorder.

Composition

Master data shell is the layout for editable reference tables (chart of accounts, product catalog, branches). It pairs a left tree-nav with a data table body that supports inline edit and bulk import.

Don't use this for: read-mostly listings — use list page shell instead. For CSV import flows use import wizard.
