Do & don't

Do

Each module surfaces one metric and one status. Drill-in for the full picture.

Don't

Show modules the role doesn’t have access to. The matrix is personalised.

Do

Sort by attention status — danger first, then warn, then ok.

Don't

Use this in place of a proper data table. The matrix is a launcher, not a workbench.

React API · CSS-only

No React export — author markup with .b-module-matrix + .b-mm-tile classes.

Composition

Module matrix composes a grid of module tiles — each a glyph + name + sub line + a count badge. It is the canonical workspace switcher / launcher on portal home for operators with many roles.

Don't use this for: a 4-up next-action grid — use quick links. For a single brand-tinted lead use stat hero.
