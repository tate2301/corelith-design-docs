Do & don't

Do

State what still works while offline. The operator needs to know what to do, not just that something’s broken.

Don't

Block the page when offline. The product is offline-first; keep working.

Do

Show the time it went offline and the queue depth.

Don't

Hide the banner once reconnected. Show "Synced 7 receipts" briefly, then dismiss.

React API · CSS-only

No React export — author markup with .b-offline-banner. Wire visibility from your sync runtime (e.g. useOnline()).

Composition

Offline banner composes an icon + status line + retry action — anchored to the top of the viewport when the device loses connectivity. It pairs with offline runtime.

Don't use this for: non-network errors — use critical strip. For per-record sync state use sync panel.
