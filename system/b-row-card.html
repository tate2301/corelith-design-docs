Row card

A tap-anywhere row that opens a detail sheet. The mobile counterpart to a data-table row — one card per record, name and sub on the left, primary number on the right.

Stable .b-row-card Tap → sheet

Default

Name, sub, and a primary number. Tap opens a bottom sheet with the full record.

3 branch rows.b-row-card

With meta row

When the record carries a couple of secondary numbers, add a meta row of label / value pairs beneath the headline. Cap at 3 pairs — past that the row no longer reads at a glance.

Composition

Row card composes from the primitives card + text + (optionally) a delta indicator. It is the mobile counterpart to a data-table row: same record, denser layout, single tap target.

Don't use this for: informational lists where tapping does nothing. For static rows use mobile list. For desktop-density tabular data with many columns use x-data-table instead.

Responsive behaviour

ViewportBehaviour
Phone (≤ 720 px)Full width. Value column shrinks to its content; sub line truncates with text-overflow: ellipsis. This is the canonical surface.
Tablet (720 – 1023 px)Constrained to a 480 px max-width column inside a card. Meta row stays inline up to 3 pairs.
Desktop (≥ 1024 px)Prefer x-data-table at this width — but a row-card list is still valid for sidebars and detail-page side panels.

Do & don't

Do

Make the whole card the tap target. The user shouldn't have to aim for the chevron.

Don't

Show a chevron on the right. The card affords tap by virtue of being a card; a chevron is visual noise.

Do

Surface the most-asked secondary number (delta, status) right under the headline value. Reading down the column should answer the operator's first question.

Don't

Cram inline actions (Edit / Delete) into the card. Open the detail sheet; put actions there.

Keyboard & accessibility

KeyBehaviour
TabFocus next row card. Each card is one stop.
Enter / SpaceActivate — opens the detail sheet or follows the href.
  • Renders as <button> when onClick is passed, <a> when href is passed — both reach by Tab and announce as a single control.
  • Accessible name composes the title + value: aria-label="Park Centre, $ 2,816, +12.4%". Sub and meta read on focus via the visible text.
  • Hover and active states are also focus-visible states — keyboard operators see the same lift.
