Do & don't

Do

Use status states for whole pages. Use empty state for inside a card.

Don't

Make the user search for what to do next. Always give a button.

Do

Tone-match the icon — danger red for errors, neutral grey for blocked.

Don't

Show "Something went wrong". Tell the operator what specifically broke.

React API · compose with EmptyState

No dedicated StatusState export. Compose EmptyState at full-area scale; props: icon · title · description · action · variant="full".

Composition

Status state composes a glyph + title + description + action — at full-page or full-card scale. Used for loading, blocked, and fatal-error states where the whole surface has no content.

Don't use this for: empty list results inside a populated page — use empty state at inline scale. For transient errors use notifications.
