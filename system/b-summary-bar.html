Summary bar

A compact one-line row of metrics under a page header. Used when 8–10 small numbers belong above the fold but don't deserve full KPI cards.

Stable .summary-bar Inline · dense

Default

Pills separated by dot. Each item is a tiny label + value.

Do & don't

Do

Keep it to a single row. No wrapping on desktop; on tablet, allow two rows.

Don't

Mix scales. Don’t have one item in millions and another in single digits.

Do

Make each pill clickable when it tap-throughs to a more detailed view.

Don't

Use this as a chart container. Use the KPI grid for that.

React API · CSS-only

No React export — author markup with .b-summary-bar and inline cells.

Composition

Summary bar composes 3 – 5 inline totals — used at the bottom of a list / table to show count, sum, average. It is the read-only counterpart to a table footer.

Don't use this for: primary KPIs — use stat hero. For per-row aggregates inside a table use a table footer.

Responsive behaviour

ViewportBehaviour
Phone (≤ 720 px)2 columns; values tabular-nums.
Tablet (720 – 1023 px)3 – 4 columns inline.
Desktop (≥ 1024 px)5 columns inline; sticky at the bottom of the list shell.
