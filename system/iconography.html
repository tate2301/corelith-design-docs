Iconography

Hand-rolled Lucide-style strokes. 1.6 px stroke, 24-unit grid, currentColor only. We never use coloured icons — colour comes from the surrounding tile or text.

100 icons 1.6 px stroke currentColor

Usage

Drop an icon anywhere a data-icon hook is present. The helper script renders SVG inline, inheriting color from its parent.

Buttons with leading icons.btn + <span data-icon="…">

Sizes

Five canonical slots — 14, 16, 18, 22, 28. Pick the smallest that reads cleanly; icons exist to label, not to draw attention.

Stroke conventions

Every glyph is drawn on a 24-unit grid with a 1.6 px stroke. Caps and joins are round. Never fill — the system is line-art only.

PropertyValueWhy
Stroke width1.6 pxReads at 16 px without smearing; thicker than Feather, thinner than Heroicons.
Stroke linecaproundEchoes the system's soft-edged radii; prevents square jaggies at low DPI.
Stroke linejoinroundSame — and prevents bevels on sharp inside corners.
Fillnone (default) · currentColor (status dots only)Filled shapes break consistency when paired with line glyphs.
Stroke / fill colourcurrentColorInherits from the surrounding text or tile — never bake colour into an SVG.
Grid24 × 24Matches Lucide, Heroicons, Tabler — easy to substitute or audit.

Colour

Icons inherit currentColor. Colour comes from the tile or the parent text; never from the SVG itself.

Adding a new icon

Five rules — bake the icon into icons.js and it picks up the rest of the system automatically.

  1. Draw on the 24-unit grid. Centre the optical mass, not the bounding box.
  2. Stroke = 1.6 px, linecap = round, linejoin = round, fill = none. Existing glyphs in icons.js all share the P constant — use it.
  3. Add the entry to the I map in /icons.js as name: `<path … ${P}/>`. Lowercase, single-word, no kebab.
  4. Pick a category in this catalog and add the cell. Don't add a new category for a single icon.
  5. Reference it as <span data-icon="name"></span>. The runtime renders it on DOMContentLoaded.
// In icons.js, append to the I map:
newicon: `<path d="M4 4l16 16" ${P}/>`,

// In product code:
<span data-icon="newicon" data-icon-size="16"></span>

Do & don't

Do

Pair an icon with a label whenever possible. Icon-only buttons need an aria-label.

Don't

Use emoji in product UI. They render differently per OS and break the visual rhythm.

Do

Keep stroke width consistent at 1.6 px. Don't fill icons — the system is line-art only.

Don't

Use colour inside an SVG path. Colour is set by the parent.

Code

<!-- Default 16 px -->
<span data-icon="settings"></span>

<!-- Larger size -->
<span data-icon="chart" data-icon-size="22"></span>

<!-- Set color via parent -->
<div style="color: var(--brand)">
  <span data-icon="plus"></span>
</div>
