Do & don't

Do

Use accordions for content the user usually skips. The default state is collapsed.

Don't

Hide critical settings inside an accordion. Putting "Save changes" inside one is a footgun.

Do

Keep section titles scannable — they’re the navigation.

Don't

Nest accordions. One level of open-and-close is the max.

React API

No React component in @corelithzw/react v0.3.0 — CSS-only primitive. A React wrapper is on the roadmap.
