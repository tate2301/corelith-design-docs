Do & don't

Do

Show who uploaded each file and when. Attachments are audit evidence.

Don't

Open the file inline. Open in a new tab or download — never replace the current view.

Do

Cap individual file size, but show the cap before the user tries.

Don't

Allow uploads of unknown file types. The list of accepted types is in the help text.

React API

No React component in @corelithzw/react v0.3.0 — CSS-only primitive. A React wrapper is on the roadmap.

For programmatic file uploads, use FileUpload — different surface (single drop zone, not a record-attached list).
