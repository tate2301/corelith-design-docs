Export menu

A small dropdown that lets the operator export the current view as PDF, CSV, or printable report.

Beta .export-menu PDF · CSV · Print CSS-only

Default

PDF
Report-style document
CSV
Raw rows for Excel
Print
Open the print dialog
Export menu

Do & don't

Do

Always offer CSV. Operators want to drop data into Excel.

Don't

Generate the file immediately. Run it in the background and notify when ready.

Do

Default to the most-used format. Track which the operator picks last and lead with that.

Don't

Limit exports to a single date range — let the user pick.

React API

No React component in @corelithzw/react v0.3.0 — CSS-only primitive. A React wrapper is on the roadmap.

Compose using DropdownMenu with custom items for CSV / PDF / Print until a dedicated wrapper ships.
