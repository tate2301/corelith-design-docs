Scroll container

A scrollable region with a styled scrollbar. Used inside cards, modals, and side panels so the scrollbar doesn't look like the OS default.

Custom scroll region

Do & don't

Do

Use a styled scrollbar when the container has a finite known height.

Don't

Wrap the whole page in a scroll container. Let the browser handle page scroll.

Do

Show the scrollbar only on hover/scroll. It should disappear when idle.

Don't

Use horizontal scroll on desktop. Resize content; only use horizontal scroll on touch.

React API

No React component in @corelithzw/react v0.3.0 — CSS-only primitive. A React wrapper is on the roadmap.

Plain wrapper class — no React component. Use as a styled scroll viewport in any layout.

CSS API

ClassEffect
