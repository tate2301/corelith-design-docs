The five stages

StageWhat happensBlock used
1 · UploadDrag a CSV/XLSX. Header row is detected.Attachment center
2 · ParseRows are tokenised; encoding is normalised.Status state
3 · MapColumns are mapped to fields. Saved templates remembered.Form shell
4 · PreviewThe first 50 rows render as the target table.Data toolbar + table
5 · CommitRows are posted in a single transaction; failures are queued.Sync panel
