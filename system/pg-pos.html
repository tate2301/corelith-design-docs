When to use

The POS terminal is for high-frequency, in-person transactions. For B2B invoicing or back-office adjustments, use the receivables data table instead. For scrap-buying with weighing scales attached, see the product catalog's per-kg variants.

Key behaviours

  • Search is global. ⌘K opens the search input from anywhere on the terminal.
  • Quantities default to 1. Per-kg items prompt for weight before adding.
  • Customer is optional for cash sales but required when paying on account.
  • Hold sale parks the cart for retrieval — useful when the customer steps away.
  • Charge is one-tap. The big blue button at the bottom right always commits the sale.
