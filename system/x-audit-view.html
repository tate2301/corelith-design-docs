Shared rules

Do

Searchable by actor, module, date.

Don't

Truncate descriptions.

Do

Include context — site, till, plant.

Don't

Allow editing audit entries. Ever.

React API · CSS-only pattern

No dedicated AuditView export — compose from DataTable + an inline diff renderer. Each row is one historical write.

Composition

Audit view composes a chronological table of writes + a per-row diff payload (before / after) + a who / when / where header. It is the canonical surface for compliance, dispute resolution, and forensic ops.

Don't use this for: live activity (use activity feed) or for discussion (use comments thread). Audit is the immutable, signed-write history.

Responsive behaviour

ViewportBehaviour
Phone (≤ 720 px)Row-card stack; tap opens diff in a bottom sheet.
Tablet (720 – 1023 px)Table + tap-to-expand diff inline.
Desktop (≥ 1024 px)Table + side diff pane that updates with row focus.
