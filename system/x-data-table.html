Shared rules

What every composition obeys.

Do

Right-align numbers, money, and dates. Left-align text. Mono numerals always.

Don't

Mix mono and proportional digits in the same column.

Do

Sticky header on scroll. Long tables become useless without it.

Don't

Use zebra-striping. Hairline borders carry the same job for less visual noise.

Do

Show row count, selected count, and pagination at the bottom.

Don't

Bury actions in a "..." menu when the operator does them all the time. Inline the top action.
