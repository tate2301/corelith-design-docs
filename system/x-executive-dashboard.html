Shared rules

Do

Lead with what needs attention. Critical strip > KPI grid > module matrix > highlights.

Don't

Use the dashboard for analytical drill-down. Awareness, not analysis.

Do

Personalise the matrix to the role. A bursar sees fees-first.

Don't

Reload the whole page when a metric refreshes. Update in place.
