React API · CSS-only pattern

No dedicated MasterData export — compose from master data shell + DataTable (with inline edit) + import wizard for bulk CSV.

Composition

Master data composes a tree-nav of entity types + an editable table for the selected type + an import affordance. It is the canonical pattern for chart of accounts, branches, product catalog, departments.

Don't use this for: transactional data (receipts, invoices) — those live in their own list / detail shells. For first-time bulk seed use onboarding.
