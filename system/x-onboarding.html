Shared rules

Do

Always allow "Skip for now". Persist progress.

Don't

Block the platform behind onboarding.

Do

Show step N of M and what comes next.

Don't

Replay onboarding on every sign-in.

React API · CSS-only pattern

No dedicated Onboarding export — compose from form shell per step + a stepper + a progress / save-as-you-go banner.

Composition

Onboarding composes a multi-step linear flow — workspace setup, role pick, first record. Each step is its own form shell with a clear primary CTA.

Don't use this for: one-off forms — those go straight in form shell. For data import use import wizard.
