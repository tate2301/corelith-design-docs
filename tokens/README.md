# Corelith Design Tokens — exports

`tokens.css` at the repo root is the **single source of truth**. The files
in this folder are machine-readable projections of it, regenerated by
[`../scripts/export-tokens.mjs`](../scripts/export-tokens.mjs).

## The three primary exports (P2·08)

| File                       | Format                                                  | Who consumes it                                              |
| -------------------------- | ------------------------------------------------------- | ------------------------------------------------------------ |
| `corelith.flat.json`       | Flat `name → value` map (`+ _dark`, `+ _meta`).         | Raw JS / native pipelines that want a one-shot lookup table. |
| `corelith.json`            | W3C DTCG / [Figma Tokens Studio](https://tokens.studio) shape. | Designers syncing Figma; Style Dictionary; theming tooling.  |
| `corelith.tailwind.css`    | Tailwind v4 `@theme { ... }` block (+ dark `@media`).   | Tailwind v4 apps — `@import` once, use `bg-canvas` etc.      |

A second pair (`tokens.json` + `tokens.dark.json`) is also kept for
backwards-compatibility with older Style Dictionary consumers and is
emitted by the separate `scripts/extract-tokens.mjs` script.

## Regenerate

```bash
npm run tokens         # or: node scripts/export-tokens.mjs
```

Edit `tokens.css` first, then re-run. The script is dependency-free.

## Tailwind radius scale

`tokens.css` uses t-shirt radii (`--radius-xs … --radius-2xl`), which map
1-for-1 onto Tailwind v4's `--radius-*` namespace. `--radius-pill` is
emitted as `--radius-full`. Numeric radii (`--radius-1 … --radius-4`)
would map `1 → sm, 2 → md, 3 → lg, 4 → xl` if introduced later.

## Dark theme

Dark tokens are sourced from the `body.is-dark` block in `tokens.css`.
They appear under the `_dark` key in both JSON exports and inside a
`@media (prefers-color-scheme: dark) { @theme { … } }` block in the
Tailwind file.

## Versioning

`_meta.version` mirrors `packages/react/package.json`. Breaking renames
follow the design-system bump policy in [`../VERSION`](../VERSION).
