Modules

What this kit covers

Five modules for the security control plane.

01
Camera management
Camera registry — site, room, IP, model, owner, status.
02
Live monitoring
Multi-camera grid; PTZ, snapshots, audio if available.
03
Playback & search
Date-range scrub; motion-bookmarked clips; download.
04
Incident logging
Open an incident, attach footage, assign, close.
05
Maintenance scheduling
Inspection, cleaning, firmware updates, replacements.
